Resonant Converters: Solved Problems

EEE 339 Power Electronics · Lectures 23–24 (Hart ch. 9) · Hart Ex 9-2, 2021 Final Q6(d), 2022 Final Q3(d) (= 2024 Final Q6(c))
ZVS equations used (Hart 9.3, the same set printed in the 2021 paper):
ω₀ = 1/√(L_rC_r), Z₀ = √(L_r/C_r) · t₁ = V_sC_r/I_o · t₂ = (1/ω₀)[sin⁻¹(V_s/(I_oZ₀)) + π] + t₁ · t₃ = (L_rI_o/V_s){1 − cos[ω₀(t₂ − t₁)]} + t₂ · V_o = V_s[1 − f_s(t₃ − t₁/2)] · V_C,peak = V_s + I_oZ₀
Condition for ZVS: I_oZ₀ > V_s. Note that V_o falls as f_s rises.

Problem 1 · Hart Example 9-2 (ZVS resonant switch converter, Lecture 24)

Given: V_s = 20 V, L_r = 1 µH, C_r = 0.047 µF, I_o = 5 A.
(a) Find the switching frequency for V_o = 10 V. (b) Find the peak voltage across D_s when it is reverse-biased.
  1. Resonant constants.
    ω₀ = 1/√(L_rC_r) = 1/√(1 µH × 0.047 µF) = 4.613 × 10⁶ rad/s
    Z₀ = √(L_r/C_r) = √(1 µH / 0.047 µF) = 4.613 Ω
  2. Check the ZVS condition (the capacitor voltage must swing back to zero): I_oZ₀ = 5 × 4.613 = 23.06 V > V_s = 20 V ✓
  3. Mode 1 (0 → t₁): switch opens, C_r charges linearly with I_o until v_C = V_s.
    t₁ = V_sC_r/I_o = 20 × 0.047 µF / 5 = 0.188 µs
  4. Mode 2 (t₁ → t₂): L_r–C_r resonance, v_C = V_s + I_oZ₀ sin ω₀(t − t₁). t₂ is when v_C returns to zero.
    sin ω₀(t₂ − t₁) = −V_s/(I_oZ₀) = −0.8672. The angle must be in the 3rd quadrant (after the peak), so
    ω₀(t₂ − t₁) = π + sin⁻¹(0.8672) = π + 1.0495 = 4.1911 rad
    t₂ = 4.1911 / (4.613 × 10⁶) + t₁ = 0.909 µs + 0.188 µs = 1.097 µs
  5. Mode 3 (t₂ → t₃): the diode across the switch conducts, so the switch can be turned on at zero voltage. i_L rises linearly from I_o cos ω₀(t₂−t₁) back to I_o:
    t₃ = (L_rI_o/V_s)[1 − cos ω₀(t₂ − t₁)] + t₂ = 0.250 µs × [1 − (-0.4980)] + 1.097 µs = 1.471 µs
  6. Mode 4 (t₃ → T): switch on, i_L = I_o, v_C = 0. Output voltage (average of v_x):
    V_o = V_s[1 − f_s(t₃ − t₁/2)], with t₃ − t₁/2 = 1.377 µs

(a) Switching frequency

10 = 20[1 − f_s × 1.377 µs] ⇒ f_s = (1 − 10/20) / 1.377 µs = 0.5 / 1.3771 µs

Check: T = 1/f_s = 2.754 µs > t₃ = 1.471 µs ✓ (all four modes fit in one period).

(a) f_s ≈ 363 kHz

(b) Peak reverse voltage across D_s

D_s is reverse-biased while C_r is charged, so its peak reverse voltage equals the peak capacitor voltage (at ω₀(t − t₁) = π/2 in Mode 2):

V_Ds,peak = V_C,peak = V_s + I_oZ₀ = 20 + 5 × 4.61 = 43.06 V

(b) V_Ds,peak ≈ 43.1 V
Note: the slide (Hart's printed solution) writes “20 + (5)(4.61) = 33 V”. That is an arithmetic slip: 20 + 23.05 = 43.1 V. Use 43.1 V.

Problem 2 · 2021 Final Q6(d) (ZVS resonant converter, 6 marks)

Given: V_s = 5 V, I_o = 3 A, L_r = 1 µH, C_r = 0.01 µF.
(i) Find the output voltage when f_s = 500 kHz. (ii) Find the switching frequency for V_o = 2.5 V.
The ZVS equations were printed on the question paper.
  1. Resonant constants.
    ω₀ = 1/√(L_rC_r) = 1/√(1 µH × 0.01 µF) = 1.000 × 10⁷ rad/s
    Z₀ = √(L_r/C_r) = √(1 µH / 0.01 µF) = 10.000 Ω
  2. Check the ZVS condition (the capacitor voltage must swing back to zero): I_oZ₀ = 3 × 10.000 = 30.00 V > V_s = 5 V ✓
  3. Mode 1 (0 → t₁): switch opens, C_r charges linearly with I_o until v_C = V_s.
    t₁ = V_sC_r/I_o = 5 × 0.01 µF / 3 = 0.017 µs
  4. Mode 2 (t₁ → t₂): L_r–C_r resonance, v_C = V_s + I_oZ₀ sin ω₀(t − t₁). t₂ is when v_C returns to zero.
    sin ω₀(t₂ − t₁) = −V_s/(I_oZ₀) = −0.1667. The angle must be in the 3rd quadrant (after the peak), so
    ω₀(t₂ − t₁) = π + sin⁻¹(0.1667) = π + 0.1674 = 3.3090 rad
    t₂ = 3.3090 / (1.000 × 10⁷) + t₁ = 0.331 µs + 0.017 µs = 0.348 µs
  5. Mode 3 (t₂ → t₃): the diode across the switch conducts, so the switch can be turned on at zero voltage. i_L rises linearly from I_o cos ω₀(t₂−t₁) back to I_o:
    t₃ = (L_rI_o/V_s)[1 − cos ω₀(t₂ − t₁)] + t₂ = 0.600 µs × [1 − (-0.9860)] + 0.348 µs = 1.539 µs
  6. Mode 4 (t₃ → T): switch on, i_L = I_o, v_C = 0. Output voltage (average of v_x):
    V_o = V_s[1 − f_s(t₃ − t₁/2)], with t₃ − t₁/2 = 1.531 µs

(i) Output voltage at f_s = 500 kHz

Check: T = 1/500 kHz = 2.000 µs > t₃ = 1.539 µs ✓

V_o = 5[1 − (500 × 10³)(1.5308 × 10⁻⁶)] = 5[1 − 0.7654] = 1.173 V

(i) V_o ≈ 1.17 V

(ii) Switching frequency for V_o = 2.5 V

t₁, t₂, t₃ depend only on V_s, I_o, L_r and C_r, not on f_s, so they stay the same.

2.5 = 5[1 − f_s × 1.531 µs] ⇒ f_s = 0.5 / 1.5308 µs = 326.6 kHz

Check: T = 3.062 µs > t₃ ✓. Lower f_s gives higher V_o, which is consistent with ZVS behaviour.

(ii) f_s ≈ 327 kHz

Problem 3 · 2022 Final Q3(d) (also 2024 Final Q6(c), word for word)

Given: parallel resonant DC-DC converter, V_s = 100 V, L_r = 8 µH, C_r = 0.32 µF, R_L = 10 Ω, f_s = 120 kHz. Output filter L_o, C_o give ripple-free output current and voltage. Find V_o.
This topic is not in your slides (it is Hart §9.6). It was asked in 2022 and 2024 with the same numbers, so it is worth learning this method.

Idea (first-harmonic method)

The switches apply a ±V_s square wave to the series L_r and parallel C_r tank. The tank filters it, so only the fundamental matters. The output rectifier, with L_o, C_o and R_L, acts as an equivalent resistor R_e in parallel with C_r. V_o is the average of the rectified capacitor voltage.

  1. Fundamental of the input square wave: V₁ = 4V_s/π = 4 × 100/π = 127.32 V (peak)
  2. Equivalent load resistor (the rectifier with an L-filter draws a square-wave current): R_e = π²R_L/8 = π² × 10/8 = 12.34 Ω
  3. Frequencies: ω₀ = 1/√(L_rC_r) = 1/√(8 µH × 0.32 µF) = 625000 rad/s (f₀ = 99.5 kHz)
    ω_s = 2π × 120 kHz = 753982 rad/s, so ω_s/ω₀ = 1.206
  4. Reactances at f_s: X_L = ω_sL_r = 6.032 Ω, X_C = 1/(ω_sC_r) = 4.145 Ω
  5. Voltage transfer from source to capacitor:
    H = Z_p/(jX_L + Z_p) with Z_p = R_e ∥ (−jX_C). Dividing through gives
    H = 1 / [1 − ω_s²L_rC_r + jω_sL_r/R_e]
    1 − (ω_s/ω₀)² = 1 − 1.206² = -0.4553; ω_sL_r/R_e = 6.032/12.34 = 0.4889
    |H| = 1/√((-0.4553)² + (0.4889)²) = 1/√(0.2073 + 0.2390) = 1.4968
  6. Capacitor voltage (peak): V_C1 = |H| × V₁ = 1.4968 × 127.32 = 190.6 V
  7. Output voltage (the full-wave rectifier with the L_o filter averages |v_C|): V_o = (2/π)V_C1 = 0.6366 × 190.6
V_o ≈ 121 V (V_o/V_s ≈ 1.21; the parallel resonant converter can step the voltage up)

One-line formula version: V_o = (8/π²)|H|V_s = 0.8106 × 1.4968 × 100 = 121.3 V.

Graph check (if the paper gives Hart's V_o/V_s curves): read the curve for Q = R_L/(ω₀L_r) = 2.0 at ω_s/ω₀ = 1.21. It gives V_o/V_s ≈ 1.2, so V_o ≈ 120 V, which agrees.
